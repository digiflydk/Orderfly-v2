# Orderfly releases

Every release bumps `version` in `package.json` (semver: minor for features, patch for fixes) and adds a line here. The number is shown at the bottom of the SuperAdmin and admin sidebars and returned by `/api/health` as `version`, so the owner can see what is live. The newest release is first.

| Release | Date | Issue/PR | What changed |
|---|---|---|---|
| 1.1.0 | 2026-11-28 | PR #942 | Release number shown in the admin portals; new development process for every task. |

Releases before 1.1.0 were not numbered; see `CHANGELOG-SUMMARY.md` and the merged pull requests.
