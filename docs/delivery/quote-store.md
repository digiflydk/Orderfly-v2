# Immutable delivery quote store

`createTrustedDeliveryQuote` and `readDeliveryQuote` are server-only preparatory services. They verify the native session and current transactional catalog:view permission for the exact brand/location. This catalog permission is staff-only preparation access and must not be wired directly to public checkout. Customer checkout requires its own authoritative customer/cart/address quote flow. No public HTTP route or server action accepts arbitrary quote economics. Only the trusted quote orchestration service may call creation after obtaining authoritative cart, route and provider data. Structural validation and hashes do not prove that external provider data is genuine.

Quotes are create-only at `deliveryQuotes/{quoteRef}`. Strict schema validation recomputes economics and checks scope/reference consistency. The schema verifies the complete contentDigest. The service additionally verifies binding fingerprint, real current-clock expiry, native ID bounds, current brand/location settings revisions, configured provider and exact pricing rules. Disabled/paused or out-of-area settings reject creation. Reads recheck current settings and expire at `now >= expiresAtMs`, irrespective of whether a later TTL cleanup has removed the record. No overwrite/update API exists.

The internal settings transaction loader is exported for this service; callers must authorize the same native scope inside the same transaction. All checks and reads precede create. Transaction retries rerun authority, revision and expiry checks. Duplicate creation conflicts and must be resolved by an authorized read; it never overwrites historical economics. There is no cleanup job, external dispatch, checkout endpoint or production write from this task. A quote alone does not enable dispatch or authorize payment.

Tests use synthetic transactional native auth fixtures, cover create/read, duplicate immutability, altered fingerprint/economics/rules, expired/future-created quotes, foreign scope, settings invalidation, revocation/revision changes during retry and anonymous requests. Run `node --test tests/unit/delivery-quote-store.cjs` and `npm run typecheck` internally.
